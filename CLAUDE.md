# «Свободно?»

Сайт бронирования общих ресурсов интерната (стиралки, комнаты, спортзал). Полное задание — [TZ.md](TZ.md).

## Стек
Python, Flask, SQLite (чистый `sqlite3`), Jinja2, обычный CSS. Пароли — `werkzeug.security`. Время — `Europe/Moscow`.

## Правила работы
- Отвечать пользователю коротко: что сделано и как проверить.
- Экономить токены: менять только нужные места, без лишних функций.
- После каждого этапа обновить этот файл, сделать коммит и push, остановиться.

## Запуск
```
pip install -r requirements.txt
flask --app app init-db
flask --app app create-owner admin
flask --app app run
```
Временные служебные команды (до панелей): `create-school "Название"`, `add-resource КОД "Название" --minutes 60 --open 07:00 --close 22:00 --limit 3`, `create-warden КОД логин "Имя"`.

## Устройство
- `app/slots.py` — сетка слотов и правила брони; лимит и вставка в одной транзакции `BEGIN IMMEDIATE`, дубль ловит `UNIQUE(resource_id, start_at)`.
- Время в базе — московское, строкой `ГГГГ-ММ-ДД ЧЧ:ММ`. Отмена брони = удаление строки.
- Воспитатель (`app/warden.py`) видит только свой интернат: каждый запрос фильтруется по `school_id`.
