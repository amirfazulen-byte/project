# Свои замеры — главный козырь проекта

Это самая важная часть подготовки. Жюри школьных конкурсов больше всего ценит работающий прототип с проведёнными испытаниями: этот критерий весит в пять раз больше остальных. Почти никакой школьный проект не приносит собственных измерений, а вы принесёте.

**Ключевой факт:** статистики по нарушениям **текста** этикеток в открытом доступе нет. Роспотребнадзор публикует данные только по цифровой маркировке, то есть по кодам. Значит, цифру, которую вы получите, до вас никто не публиковал. Так и говорите на защите.

Всё делается из дома за один вечер. Магазин не нужен.

---

## Часть 1. Аудит 30 карточек (2–3 часа)

### Как собирать
1. Откройте Wildberries или Ozon, выберите **одну** категорию. Лучше всего «Детская одежда» или «Продукты питания — снеки»: там много мелких продавцов.
2. Берите карточки подряд из выдачи, не выбирая «плохие». Иначе результат нечестный, и на защите это вскроется.
3. В карточке ищите фотографию этикетки или бирки. Их обычно размещают последними в галерее фото.
4. Если фотографии этикетки нет вообще — это тоже результат, отмечайте отдельной строкой «нет фото этикетки».
5. Проверяйте каждую карточку своим сайтом, а не глазами.

### Таблица (заведите в блокноте или таблице)

| № | Ссылка | Фото этикетки есть | Чего не хватает | Процент | Светофор |
|---|---|---|---|---|---|
| 1 | | да / нет | адрес, номер партии | 73% | красный |
| 2 | | | | | |
| … | | | | | |
| 30 | | | | | |

### Что считать в конце
- Сколько карточек из 30 **вообще не имеют** фотографии этикетки.
- Сколько карточек не проходят проверку (красный светофор).
- **Какое обязательное сведение отсутствует чаще всего.** Это самая сильная цифра: «в 19 из 30 карточек не указан юридический адрес изготовителя».
- Средний процент соответствия по категории.

### Как это звучит на защите
> «Я проверил 30 карточек детской одежды на Wildberries. В 11 из них вообще нет фотографии бирки. Из оставшихся 19 только 4 содержат все обязательные сведения по ТР ТС 017/2011. Чаще всего отсутствует номер партии — в 14 карточках из 19. Такой статистики в открытом доступе нет, Роспотребнадзор публикует данные только по кодам маркировки.»

## Часть 2. Проверка точности сайта (40 минут)

Жюри обязательно спросит: «А ваш ИИ не ошибается?» Нужен честный ответ с числом.

1. Возьмите **5 этикеток** из своего аудита.
2. Проверьте каждую **вручную**: откройте чек-лист из `PROMPT_BIRKA.md` (раздел 4) и своими глазами отметьте, какие сведения есть, а какие нет.
3. Сравните с тем, что выдал сайт.
4. Посчитайте: сколько пунктов из всех проверенных совпало.

| Этикетка | Пунктов проверено | Совпало | Что сайт пропустил | Что сайт нашёл лишнего |
|---|---|---|---|---|
| 1 | 11 | 10 | не увидел дату | — |
| … | | | | |

**Итог:** «Сверил 5 этикеток вручную: совпадение 52 пункта из 55, то есть 94,5%. Чаще всего ИИ не распознаёт дату изготовления, когда она выбита на упаковке, а не напечатана. Поэтому в приложении есть ручной ввод текста.»

Если точность получится низкой, **не скрывайте это.** Скажите честно и объясните, что делать: вставка текста вручную и проверка пользователем. Признанное ограничение выглядит сильнее, чем скрытое, и жюри это засчитает.

## Часть 3. Опрос клиентов (1–2 часа, по желанию)

Это превращает идею в подтверждённый спрос. Если успеете — очень усилит защиту.

Обзвоните **10 типографий и дизайн-студий в Казани**, которые делают макеты этикеток. Найти их можно в Яндекс Картах по запросу «печать этикеток» или «дизайн упаковки».

Говорите так:
> «Здравствуйте! Я школьник, делаю проект для конкурса ИТ-парка. Можно три вопроса про этикетки? Вы проверяете макеты на соответствие техрегламенту? Сколько времени на это уходит? Что происходит, если в напечатанном тираже находят ошибку?»

Записывайте ответы дословно. Ищите в них:
- сколько времени уходит на одну проверку;
- был ли случай с испорченным тиражом и на какую сумму;
- кто за ошибку отвечает, типография или заказчик.

**Что просить в конце:** «Если я сделаю сервис, который проверяет макет за минуту, попробуете?» Если скажут да — попросите написать это в одном сообщении в мессенджере. Два таких сообщения — это уже письма о намерениях, и на защите вы показываете их скриншоты.

### Как это звучит
> «Обзвонил 10 типографий Казани. Семь проверяют макеты вручную, тратят от 20 минут до часа. Две рассказали про испорченные тиражи — на 40 и 120 тысяч рублей. Две готовы протестировать сервис, вот их ответы.»

---

## Что в итоге несёте на защиту

1. Цифру по 30 карточкам — ваша собственная статистика, которой нет в открытом доступе.
2. Точность сайта в процентах с честным указанием, где он ошибается.
3. Ответы типографий, если успели.

Этих трёх пунктов достаточно, чтобы проект перестал быть «идеей» и стал «проверенным решением». Разница в оценке огромная.
